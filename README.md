# Cloud removal from satellite images
Итоговая аттестационная работа, выполнялась проектной командой на тему «Очистка космических снимков от облаков».

Работа выполнялась в рамках дополнительной профессиональной программы профессиональной переподготовки в учреждении высшего образования "Московский авиационный институт (национальный исследовательский университет)".

Цель работы – разработать эффективный алгоритм автоматической очистки космических снимков от облачности, который позволит улучшить качество и доступность данных дистанционного зондирования Земли. Это обеспечит более точный анализ поверхности планеты для различных применений, включая мониторинг окружающей среды, сельское хозяйство, урбанистическое планирование и оперативное реагирование на чрезвычайные ситуации. 

SpA-GAN_for_cloud_removal-master - архив с кодом и датасетом для обучения.

ИАР mai - отчёт по итоговой аттестационной работе программы.
