# Cleaning-clouds-from-stellite-images
Итоговая аттестационная работа, выполненная в формате IT-проекта на тему «Алгоритм очистки космических снимков от облаков». Работа выполнялась в рамках дополнительной профессиональной программы профессиональной переподготовки в учреждении высшего образования "Московский авиационный институт (национальный исследовательский университет)".
